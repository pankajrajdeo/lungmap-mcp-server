## [Unreleased]

### Added
- Initial release of LungMAP MCP Server
- 8 comprehensive LungMAP API tools
- 3 workflow prompts for common research tasks
- 2 resource endpoints for API documentation
- Comprehensive documentation and setup guides
- Claude Desktop integration support
- LangChain integration support

### Features
- **search_datasets**: Primary discovery tool for datasets, genes, and entities
- **get_dataset_details**: Comprehensive dataset information
- **get_sample_details**: Sample metadata and donor information
- **get_analysis_results**: Computational analysis results
- **get_molecular_entities**: Gene sets, probes, cell types, anatomy terms
- **get_infrastructure_resources**: Researchers, sites, and technologies
- **list_controlled_vocabulary**: Valid filter values for searches
- **search_media**: Files and images across all datasets

### Documentation
- README with comprehensive setup instructions
- Quick Start guide for rapid deployment
- Installation guide for various environments
- Deployment checklist for production use
- MCP configuration examples for different clients
- Tool usage guide with examples

### Configuration
- Support for Claude Desktop integration
- Support for LangChain/LangGraph integration
- Multiple deployment configurations
- Virtual environment support
- Docker-ready structure
