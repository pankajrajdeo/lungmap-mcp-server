# 📚 Examples

This directory contains example configurations and usage patterns for the LungMAP MCP Server.

## Files

- **`mcp_config_examples.json`** - Configuration examples for different MCP clients (Claude Desktop, LangChain, etc.)

## Usage

### Claude Desktop Configuration

Copy the appropriate configuration from `mcp_config_examples.json` to your Claude Desktop config file:

**macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`  
**Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

### LangChain Integration

See the examples in the main [README.md](../README.md) for LangChain usage patterns.

### Custom Configurations

Modify the examples in `mcp_config_examples.json` to fit your specific setup (virtual environments, custom paths, etc.).
